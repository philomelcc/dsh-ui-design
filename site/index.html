怎么用

三种用法，按你的角色挑一条。

①

给 AI 用

插件注册了 ui_design 工具。做前端 UI 任务前先 search，匹配再 get 拿提示词和 demo——搜不到合适的就自己设计，不硬套。

ui_design search "列表转圈 loading"
②

给人用

页面里按 tag 筛、按名字搜，点卡片看可交互 demo。右边「实现提示词」一键复制，粘给任何 AI 都能按同一套设计实现。

点卡片 → 复制提示词 → 粘给 AI
③

装进 dsh

装好后重启一次 dsh web，工作台第二行会出现 tab「UI设计」；没装工作台就装在系统栏。

dsh plugin --profile web add @philomelcc/dsh-ui-design

浏览设计

加载中…

点开卡片看演示和适用场景；复制「实现提示词」粘给任何 AI，它就能按同一套设计实现。每项都标了「适用 / 不适用」，用之前先对一下场景——没有合适的就别硬套。
